## What it does for you

| | |
| --- | --- |
| **Faster, cleaner games** | GPU, Windows gaming levers, network path, and everyday clients (Steam, Discord, …) tuned for play |
| **Built for *your* machine** | Detects hardware and software first — no blind one-click registry spam |
| **Honest status** | Applied only when verification proves it — not green for show |
| **Safe to try** | Snapshots before writes where possible · no tray agent · elevate per action |

## How you use it

1. Download **Exo.exe** from [Releases](https://github.com/ImAvgErix/Exo/releases/latest)  
2. Run the Windows installer → Start menu → open Exo  
3. Detect → pick modules → apply → verify  

Windows 11 x64. Builds are unsigned; SmartScreen may ask once.
